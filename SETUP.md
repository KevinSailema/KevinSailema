## How to Use

### Option 1: GitHub Profile README (Recommended)

1. Create a repository named `KevinSailema` (your username)
2. Copy the contents of `README.md` to your new repository
3. Push to GitHub
4. Your profile will automatically display the README!

```bash
mkdir KevinSailema
cd KevinSailema
git init
git add README.md assets/
git commit -m "Initial commit: Professional Profile README"
git branch -M main
git remote add origin https://github.com/KevinSailema/KevinSailema.git
git push -u origin main
```

### Option 2: Portfolio Website

1. Host `index.html` on GitHub Pages or any web server
2. Update links in the HTML to point to your actual profiles
3. Share the URL in your CV and social media

```bash
# If using GitHub Pages:
git branch -m gh-pages
git push -u origin gh-pages
# Your site will be available at: https://KevinSailema.github.io/KevinSailema
```
